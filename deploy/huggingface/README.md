# VoxGuard AI backend

This Space serves the existing FastAPI endpoints alongside a Gradio status page.
It performs CPU inference using PyTorch, FFmpeg and official checksum-verified AASIST weights. The Space uses torch 2.8.0 because its ZeroGPU configuration rejects the local 2.6 baseline. Hosted 2.8 inference still requires verification; local dependency pins are unchanged. The root requirements deliberately do not include ml/requirements.txt, which pins the local environment.

Upload the contents generated by `python scripts/package_hf_backend.py` to the Space root, preserving the backend/ and ml/ directories. Do not upload the ZIP as a single repository file.

The intended frontend origin is https://voxguardai-frontend.vercel.app. Override VOXGUARD_CORS_ORIGINS in Space variables if needed. No model API key is required.

After the Space starts, open its direct https://...hf.space/api/health address. Confirm ffmpeg_available and model.available, then configure Vercel VITE_API_BASE_URL to the direct Space origin (without /api or a trailing slash) and redeploy the frontend. Test an actual short speech upload from Vercel.

Hosting access, free hardware eligibility, startup and idle limits must be verified in the user's account. The Space uses CPU inference; it does not request ZeroGPU acceleration. Packaging this service does not demonstrate that the selected host will accept or run it. Free hosting may sleep; always-on availability is not promised.

The Space requirements are self-contained: Hugging Face installs this file from /tmp before copying application folders, so relative -r includes must not be used.
