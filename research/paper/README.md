# Manuscript artifacts

- `manuscript.md`: detailed system/protocol draft, measured pilot, explicit missing experiments.
- `manuscript.tex`, `references.bib`: IEEE-style two-column source and citations.
- `manuscript.pdf`: compiled draft; not a claim of submission readiness.
- `pilot_scores.pdf`: plot of the six actual recorded convenience-pilot outputs, generated by `plot_pilot.py`.
- `references_verified.md`: verification scope and official sources.

The source uses `IEEEtran` conference style and its bibliography when installed. This machine has TeX Live and BibTeX but lacks `IEEEtran.cls`/`IEEEtran.bst`, so the delivered PDF was compiled using an explicit two-column article/numbered-reference fallback. It is IEEE-style, **not** venue-compliant camera-ready IEEE formatting. Do not submit the placeholder author block. Installing IEEEtran changes the layout and requires a fresh layout review.

From this directory:

```sh
pdflatex -interaction=nonstopmode -halt-on-error manuscript.tex
bibtex manuscript
pdflatex -interaction=nonstopmode -halt-on-error manuscript.tex
pdflatex -interaction=nonstopmode -halt-on-error manuscript.tex
```

The same executable commands work in PowerShell with a local TeX distribution installed. To regenerate the actual-data figure from the repository root:

```sh
python -m pip install -r research/requirements.txt
python research/paper/plot_pilot.py
```

Matplotlib configuration/cache must be writable (`MPLCONFIGDIR` may be set to a task-local directory). Figure generation consumes `research/results/pilot_scores.csv`; no placeholder metric, invented recording, or decision threshold is generated.

No new representative validation/test corpus was obtained in the latest acquisition pass. Correctly frozen operating thresholds, modern/unseen-generator evidence, representative uncertainty estimates, Indic-language evaluation and empirical hybrid comparisons are prerequisites for the intended empirical paper. Dataset access findings and manual-import instructions belong to `research/datasets/`. This draft must be updated from recorded evaluation outputs when those prerequisites become available.
